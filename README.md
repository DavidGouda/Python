# Python Fundamentals – Employee Data Analysis

## Project Overview

This project focuses on analyzing employee and project data using Python.

The project was completed as part of the Skillovilla Python Fundamentals Capstone.

## Dataset

The project used employee and project-related data containing:

- 5 employees
- 14 project records
- 3 dataframes

## Analysis Performed

The project included 10 assigned tasks using Python for data analysis.

The analysis involved:

- NumPy
- Pandas
- Data handling and manipulation
- Working with multiple dataframes
- Joining data
- Handling missing project costs
- Calculating bonuses
- Applying designation rules
- Summarizing total project costs
